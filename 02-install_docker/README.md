# Role: 02-install_docker

## Описание
Роль для установки Docker на Debian/Ubuntu системах с автоматическим определением дистрибутива.

## Переменные
- `docker_required_packages` - пакеты, необходимые для установки Docker
- `docker_packages` - пакеты Docker для установки

## Особенности
- Автоматически определяет дистрибутив (Ubuntu/Debian)
- Использует правильные GPG ключи и репозитории для каждого дистрибутива
- Добавляет пользователя в группу docker
- Запускает и включает сервис Docker

## Пример использования
```yaml
- hosts: servers
  roles:
    - 02-install_docker
```

## Требования
- Ansible 2.9+
- Debian/Ubuntu система
- sudo права
- Интернет соединение для загрузки GPG ключей
